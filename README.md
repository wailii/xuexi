# 学习

在手机上跟 AI 导师对话学东西：说想学什么，它先联网查资料、排好一门课，再一节一节带你学，有复习、小测和笔记。

## 下载

**[点这里下载 学习 v1.6.4（安卓，12 MB）](https://github.com/wailii/xuexi/releases/latest/download/xuexi-v1.6.4.apk)**

**怎么装**：用手机浏览器点上面的链接，下载完点开安装包。手机提示「未知来源」或「外部来源应用」时选允许（vivo 要先勾「已了解风险」再点继续安装）。

- 需要安卓 11 及以上
- 装好不用填 Key 就能先体验：建 1 门课、和导师聊 10 次
- 体验完在设置里填自己的大模型接口（OpenAI 兼容的地址 + Key + 模型名）；联网查资料和课程封面用阿里云百炼的 Key

## 源码

- `web/`：页面代码（App 的界面和逻辑都在这）
- `android/`：安卓 WebView 壳，`./build-apk.sh` 打包
- `prototype/`：最早的 HTML 原型，`design/`：角色和图标方案
- `tools/`：电脑上调试和截图的脚本
